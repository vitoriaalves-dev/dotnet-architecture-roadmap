# To-Do App – Requisitos

## Visão Geral
API REST para gerenciamento de tarefas, com operações básicas de CRUD.

## Requisitos Funcionais
- Criar uma tarefa
- Listar todas as tarefas
- Obter tarefa por ID
- Atualizar uma tarefa
- Excluir uma tarefa

## Campos da Tarefa
- Id (Guid)
- Título (string)
- Descrição (string)
- Concluída (bool)
- Data de criação (DateTime)

## Requisitos Não Funcionais
- API REST em ASP.NET Core
- Persistência inicial em memória
- Código organizado por responsabilidades
