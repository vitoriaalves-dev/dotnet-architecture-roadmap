# Semana 1 – Ciclo de Vida de Software e Levantamento de Requisitos

## Ciclo de Vida de Software
O ciclo de vida de software descreve as etapas pelas quais um sistema passa, desde a ideia
até sua manutenção. As etapas principais são:

- Levantamento de requisitos
- Análise e design
- Implementação
- Testes
- Deploy
- Manutenção

Um erro comum é iniciar a implementação sem entender claramente o problema, o que gera
retrabalho e código difícil de manter.

## Importância dos Requisitos
Requisitos bem definidos:
- Reduzem retrabalho
- Facilitam testes
- Ajudam a tomar decisões arquiteturais
- Tornam o código mais legível e organizado

Nesta semana, o foco é **entender o problema antes de escrever código**.
