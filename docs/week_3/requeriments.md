# Sistema de Notificações – Requisitos

## Funcional
- Enviar notificação por Email
- Enviar notificação por SMS
- Enviar notificação por Push

## Regras
- O sistema deve permitir adicionar novos tipos de notificação
  sem alterar código existente
- O envio deve ser abstraído por interface

## Não funcional
- Aplicação console
- Sem dependência externa
- Implementação focada em padrões de projeto
