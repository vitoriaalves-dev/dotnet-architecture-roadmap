# Semana 4 – UML aplicada

UML é uma linguagem de modelagem usada para comunicar
a estrutura e o comportamento de sistemas.

Nesta semana, o foco é:
- Comunicar responsabilidades
- Tornar o fluxo do sistema explícito
- Apoiar decisões arquiteturais

Diagramas escolhidos:
- Caso de Uso → visão funcional
- Sequência → fluxo de execução

Não foi utilizado diagrama de classes para evitar redundância,
já que o código já expressa bem a estrutura.
